# The Frontier Atlas

A standalone interactive atlas for an original three-book Wild West universe.

## Included
- Interactive SVG frontier map
- Pan and wheel zoom
- Searchable settlements and landmarks
- Map-layer filters
- Book I / II / III filtering
- Animated story routes
- Pulsing location markers
- Responsive desktop/mobile panels
- Cinematic opening screen
- No framework, build step, database, or Vercel dependency

## GitHub Pages
The repository includes a GitHub Actions workflow at `.github/workflows/pages.yml`.

After GitHub Pages is enabled for the repository, pushes to `main` deploy the site automatically.
